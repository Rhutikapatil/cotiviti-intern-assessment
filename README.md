# Data

The raw data is not included in this repository. Download it from Kaggle:

**Healthcare Provider Fraud Detection Analysis** (Gupta, 2019)
https://www.kaggle.com/datasets/rohitrox/healthcare-provider-fraud-detection-analysis

Place these four files in this `data/` folder (the long number in each name is expected):

| File | Contents |
|---|---|
| `Train-1542865627584.csv` | Provider fraud labels |
| `Train_Beneficiarydata-1542865627584.csv` | Patient details |
| `Train_Inpatientdata-1542865627584.csv` | Hospital stay claims |
| `Train_Outpatientdata-1542865627584.csv` | Outpatient claims |

The `Test` files are not used because they have no fraud labels.
